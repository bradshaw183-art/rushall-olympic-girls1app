# Rushall Olympic Girls Android App

Premium mobile club hub for Rushall Olympic Girls FC.

## Included

- Native Android shell with secure WebView navigation
- Branded, touch-friendly offline home dashboard
- Fixtures, Parent Hub, registration, fees, shop and Boot Bank shortcuts
- U8, U9 and U10 team access
- Maps/contact links open in the appropriate Android app
- Sideloadable APK built automatically by GitHub Actions

The first release uses the club website as the live source for transactional and frequently updated content, so parents always see current information without reinstalling the app.
